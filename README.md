# Todo App

A full-stack **Todo Application** built using the **MERN Stack** — **MongoDB, Express.js, React.js, and Node.js**.  
This project helps users manage daily tasks efficiently with features like adding, updating, completing, and deleting todos through a clean and responsive interface.

## Features

- Add new tasks
- Edit existing tasks
- Delete tasks
- Mark tasks as completed
- Store todos in MongoDB
- Responsive frontend UI
- Full-stack integration between React frontend and Node/Express backend

## Tech Stack

### Frontend
- React.js
- CSS 

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose
